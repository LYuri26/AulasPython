# AulasPython

Este repositório contém aulas e materiais didáticos sobre a linguagem Python, voltados para alunos de cursos técnicos em Informática. O foco é fornecer exemplos práticos, exercícios resolvidos e atividades comentadas que ajudam na fixação dos principais conceitos da linguagem.

## Conteúdo

- Fundamentos da linguagem Python (sintaxe, variáveis, tipos de dados);
- Estruturas de decisão e repetição;
- Funções, listas, tuplas, dicionários e conjuntos;
- Programação orientada a objetos em Python;
- Exercícios práticos e scripts funcionais;
- Códigos organizados por nível de dificuldade e assunto.

## Público-alvo

Alunos de cursos técnicos, professores de disciplinas de programação e iniciantes que desejam aprender Python de forma prática, objetiva e progressiva.

## Requisitos

- Interpretador Python (preferencialmente Python 3.x);
- Editor de código (VSCode, PyCharm, Thonny, etc.);
- Conhecimentos básicos de lógica de programação.
